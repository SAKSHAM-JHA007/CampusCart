- Product name
- Price
- Condition
- Description
- Seller
- Verified student badge
- College
- General pickup area
- Express Interest
- Report Listing

Do not publicly display exact hostel rooms or exact home addresses.

9. EXPRESS INTEREST
This replaces Cart and Checkout.

Buyer:
Product → Express Interest → Interest Created → Seller Notified

Seller:
New Interest → View Buyer → Accept / Reject

If accepted:
Buyer + Seller → Contact Information → Safe Meetup Point → Physical Handoff

No online payment in MVP.

10. SAFE MEETUP
Create predefined safe meetup locations around BMSIT:
- BMSIT Main Gate
- Library Entrance
- Security Post
- Other designated campus locations

Outcomes:
- Completed
- Fell Through

Never reveal exact residential addresses or hostel room numbers.

11. TRANSACTION / HANDOFF LOG

17. BACKEND / REST API
Use Node.js with Next.js API routes / REST APIs.

Authentication:
POST /api/auth/signup
POST /api/auth/login
POST /api/auth/verify

Users:
GET /api/users/profile
PUT /api/users/profile

Products:
GET /api/products
POST /api/products
GET /api/products/:id
PUT /api/products/:id
DELETE /api/products/:id
PATCH /api/products/:id/status

Search:
GET /api/products/search
GET /api/products/filter

Interest:
POST /api/interests
GET /api/interests
PATCH /api/interests/:id

Transactions:
POST /api/transactions
GET /api/transactions
PATCH /api/transactions/:id

Reports:
POST /api/reports
GET /api/admin/reports

Admin:
GET /api/admin/users
GET /api/admin/products
PATCH /api/admin/products/:id
PATCH /api/admin/users/:id

22. ANALYTICS & SUCCESS METRICS
Track:
- Registered users
- Verified students
- Active listings
- Weekly active buyers
- Product views
- Express interests
- Completed handoffs
- Reported incidents
- Sellers listing multiple items

Phase 1 targets:
- 150+ active listings
- 250–300 weekly active buyers
- More than 25% listing-to-contact rate
- More than 40% contact-to-completed-handoff rate
- 20% of sellers listing 2+ items
- 0 reported safety incidents
